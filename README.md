# Personal CV Website
[Preview Website](https://minciunadavid06.github.io/HW-EWD2/)
## Descriere

Acest proiect reprezintă un **website personal de tip CV/portofoliu**, realizat folosind **HTML, CSS și JavaScript**. Scopul proiectului este prezentarea informațiilor personale, a abilităților, a proiectelor realizate și a unor elemente interactive precum o pagină de overview, o carte de vizită digitală și un chatbot simplu.

Website-ul este structurat în mai multe pagini interconectate și oferă o experiență simplă, clară și plăcută de navigare.

---

## Obiective

- Crearea unui CV online
- Prezentarea informațiilor personale
- Prezentarea proiectelor personale
- Realizarea unei cărți de vizită digitale
- Implementarea unei pagini de overview
- Crearea unui chatbot simplu folosind JavaScript
- Exersarea tehnologiilor HTML, CSS și JavaScript
- Realizarea unei interfețe web responsive de bază
- Aplicarea unui design inspirat dintr-un layout realizat în Figma

---

## Tehnologii utilizate

- HTML5
- CSS3
- JavaScript
- Figma
- GitHub Pages

## Structura proiectului

Proiectul conține următoarele fișiere:

```text
index.html          -> Pagina principală a website-ului
CV.html             -> Pagina de CV cu informații personale și abilități
Proiecte.html       -> Pagina dedicată proiectelor personale
contact.html        -> Pagina de contact cu formular
overview.html       -> Pagina de prezentare generală a profilului, skill-urilor și proiectelor

card.html           -> Pagina pentru cartea de vizită digitală

chatbot.html        -> Pagina care conține interfața chatbot-ului

chatbot.js          -> Logica chatbot-ului și întrebările interactive

figma-auth.css      -> CSS exportat/inspirat din designul realizat în Figma pentru pagina de autentificare

style.css           -> Fișierul principal de stilizare pentru website

da.jpg              -> Imagine folosită ca poză de profil în pagina Business Card
Frame 1.png         -> Imagine/export din Figma folosit ca referință vizuală pentru design
